# Images

- `profile.jpg` : your portrait, shown as a circle beside your name. Use a square crop, at least 400 x 400 px, under 200 KB. Keep the face in the upper-middle of the frame.
- `hero-thermal.jpg` : a thermal image for the home page, about 1200 px wide and under 300 KB.

Both are optional. If a file is missing, that element stays hidden (the hero shows the interactive demo instead of a thermal image).
To change the alt text and caption of the thermal image, edit the `hero-image-figure` block in `index.html`.
